# Domain docs live in each repo

This workspace keeps no glossary or ADRs of its own. Each code repo holds the docs for its project; for Argos, in any Argos worktree (`worktrees/argos/<branch>/`):

- `CONTEXT.md`: the glossary.
- `docs/adr/`: Argos's ADRs, named per `docs/agents/domain.md`.

Change them through an Argos PR. Only docs about this workspace itself belong in this folder.
